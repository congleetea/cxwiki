# VAE / CVAE 原始来源与核验

获取与核验日期：2026-11-20。本文为概念解释，未复现论文训练或性能。

## 核心论文

- Kingma、Welling，Auto-Encoding Variational Bayes，首次提交 2013-12-20，ICLR 2014。[论文页](https://arxiv.org/abs/1312.6114)，[已读 v11 HTML](https://arxiv.org/html/1312.6114v11)，[本地 PDF](../papers/kingma-welling-vae-1312.6114.pdf)。§2.2 下界，§2.3–2.4 随机估计与重参数化，§3 高斯 VAE，附录 B 高斯 KL，附录 C Bernoulli／Gaussian 观测分布。PDF 是本次下载的论文站点版本，HTML 明确固定 v11。
- Sohn、Yan、Lee，Learning Structured Output Representation using Deep Conditional Generative Models，NeurIPS 2015。[官方 PDF](https://papers.nips.cc/paper/2015/file/8d55a249e6baa5c06772297520da2051-Paper.pdf)，[本地 PDF](../papers/sohn-cvae-neurips-2015.pdf)。§4 式 (4)–(5)：条件先验、近似后验、条件生成模型与 CVAE 下界；原论文输入 x／输出 y，正文统一重命名为条件 c／输出 x。
- Rezende、Mohamed、Wierstra，[Stochastic Backpropagation and Approximate Inference in Deep Generative Models](https://arxiv.org/abs/1401.4082)，ICML 2014；并行历史工作，核对论文页与摘要，不声称逐节阅读。

## 补充解释与应用

- Kingma、Welling，[An Introduction to Variational Autoencoders，v3](https://arxiv.org/html/1906.02691v3)，§2，重点 §2.4–2.5：重参数化梯度、因子高斯与采样优化；用于核验概念解释。
- Zhao 等，[ACT v1](https://arxiv.org/html/2304.13705v1)，§IV-B–C、算法 1–2：训练后验读本体状态与动作、解码策略读图像和本体状态；推理设 z=0。该版本算法 1 列 MSE；本文不把它与其他实现的 L1 等损失混写。
- Rombach 等，[Latent Diffusion v2](https://arxiv.org/html/2112.10752v2)，§3.1–3.2：感知压缩、KL／VQ 两类正则方案与潜空间扩散。不是只靠基础 VAE 的一次先验抽样生成高质量图像。

## 本文原创解释

一维 KL 数值、固定噪声的重参数化手算、绕障两条路径与条件均值示例为原创教学推导。四张 SVG / PNG 是原创图，不是论文实验图。异常检测为框架导出的应用思路及局限，不作为经本文验证的检测方法。未报告生成质量、异常检测准确率或机器人成功率。

## 相邻页面修正

交叉熵页原来把所有 VAE 重建项等同交叉熵，改为按观测似然区分 Bernoulli BCE 与固定方差 Gaussian 平方误差；激活函数页澄清 SoftPlus 是正尺度参数化的一种选择，而非重参数化必需形式。
